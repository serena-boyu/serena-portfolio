Design project by Serena Ng

The Pomodoro Timer

A non-distracting yet satisfying productivity tool for the Apple Watch

  • Role: Sole Designer, UI Design, Interaction Design, Visual Specifications

An Apple Watch app that brings the Pomodoro Technique to the wrist — set a focus length, a break length, and a number of sets, then let the watch handle the rhythm while you keep your phone out of reach.

The design leans on the Watch's constraints rather than fighting them: a single ring carries the timer and productivity stats sit one swipe away. Complications surface remaining focus and break time directly on the watch face, so checking progress never means opening the app.

I documented the full system — color, type, UI component dimensions, complications, and the end-to-end workflow — as a set of visual design specs ready for handoff.
